# Projects

## tphysics

**Status:** Open Source  
**URL:** [github.com/thebillington/tphysics](https://github.com/thebillington/tphysics)

A physics simulation library for teaching and learning A-Level Physics concepts, built as an interactive web application.

- Interactive simulations for mechanics, waves, and electromagnetism
- Built with TypeScript and Canvas API
- Used in classroom teaching for A-Level Physics students
- Open source with community contributions

## Ecoworks Monitoring System

**Status:** Personal Project

An IoT-based environmental monitoring system for tracking and visualising energy consumption and environmental data in real-time.

- Raspberry Pi-based sensor data collection
- Real-time dashboard with historical analytics
- Energy consumption tracking and reporting
- Cloud-based data pipeline with AWS IoT

## Mushy's Adventure

**Status:** Personal Project

A 2D platformer game built in Unity for mobile devices, featuring custom physics, procedural level generation, and pixel-art graphics.

- Custom physics engine for platforming mechanics
- Procedural level generation algorithms
- Unity with C# scripting
- Published on Android Play Store
